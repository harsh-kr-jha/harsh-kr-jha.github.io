Installation

Opening Headwig on your Mac

Headwig is unsigned, so macOS can’t verify its developer. Only continue if you trust this download.

  1. Install Headwig, then try opening it once. Dismiss the macOS warning.
  2. Open System Settings → Privacy & Security. Scroll to Security and click Open Anyway for Headwig.
  3. Confirm with Open when prompted. You only need to approve it the first time.
